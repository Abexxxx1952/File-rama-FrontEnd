# File-rama FrontEnd

Frontend for a cloud storage application that provides functions for registering and authorizing users, uploading and managing files and folders, maintaining statistics on storage usage. This project is written in NextJS

## Installation

```bash
git clone https://github.com/yourusername/file-rama.git
cd file-rama
npm install
npm run dev
```

## Usage

After logging in, you can:

- **Create Folders** - Organize your files by creating new folders
- **Upload Files** - Upload multiple files with real-time progress tracking
- **Delete Files and Folders** - Remove unwanted files or entire folders
- **Rename** - Rename files and folders to keep your storage organized
- **Share Access** - Generate public links to share files with others
- **Download Files** - Download your files anytime
- **View Statistics** - Track your storage usage with interactive charts

## Functionality

The frontend provides the following features:

1. User Authentication. Register and log in using email and password. Social login via Google and GitHub. Google reCAPTCHA protection.
2. File Management. Upload, download, organize files and folders. Real-time upload progress tracking.
3. Public Sharing. Share files with public links.
4. View statistics on storage usage with interactive charts.
